# 版本状态

产品名称始终是“嘎嘎鸭智能体快速开发部署平台 / `gagaduck-agents-platform`”。本站导航中的 **V2** 仅表示当前文档和代码代际。

## 当前 V2 依据

- Kubernetes 一体化清单名为 `gagaduck-agents-platform-v2.yaml`；
- 清单中的平台镜像当前统一使用 `:v2` 标签；
- Builder 服务配置声明应用版本 `2.0.0`；
- Agent Builder 导出配置使用 `schema_version: 2.0`。

## 仍需统一的口径

| 位置 | 当前情况 | 发布建议 |
| --- | --- | --- |
| 前端包版本 | `package.json` 仍为 `0.1.0` | 明确其是包版本，或同步产品发布版本 |
| 前端产品文案 | 部分本地化资源仍保留旧品牌文案 | 统一为正式中英文名称 |
| 前端 README | 依赖版本描述可能早于当前代码 | 从 lockfile/构建结果更新 |
| 后端端口说明 | 服务 README 与部署清单存在差异 | 以部署配置和自动生成参考为准 |
| 镜像标签 | `v2` 无法唯一定位构建 | 发布时补充不可变 digest 或精确版本 |

:::caution 兼容性判断
不要仅凭 `:v2` 镜像标签判断完整系统兼容。正式 Release 应提供统一的 release manifest，记录前端、各微服务、数据库迁移、基础设施最低版本和部署清单之间的对应关系。
:::
