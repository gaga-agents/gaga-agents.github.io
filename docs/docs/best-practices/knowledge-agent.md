# 构建知识型智能体

知识型智能体的重点不是“上传文档后能聊天”，而是稳定找到正确证据、表达来源与不确定性，并在知识更新后可回归验证。

![知识型智能体示例](/img/screenshots/knowledge-agent.webp)

## 推荐流程

1. **定义问题范围**：列出应该回答、应该拒绝和应该转人工的问题。
2. **整理知识源**：确认文档责任人、版本、有效期和访问权限。
3. **独立验证检索**：先在知识库中测试召回，不要急于绑定智能体。
4. **配置回答规则**：要求基于证据回答，信息不足时明确说明。
5. **建立测试集**：包含直接事实、跨段信息、无答案和过期资料问题。
6. **观察与迭代**：区分解析、切分、召回、重排和生成问题。

## Prompt 要点

```text
只使用提供的知识证据回答业务事实。
证据不足时说明“当前知识库没有足够信息”，并列出缺少的信息。
不要把模型常识伪装成知识库内容。
回答中保留文档名称或证据标识，便于复核。
```

## 常见误区

- 用更长 Prompt 掩盖召回不到正确 Chunk；
- 将多个完全不同权限域的资料放进同一知识库；
- 文档更新后只追加、不处理旧版本；
- 仅评价文案流畅度，不检查引用是否支持结论。
