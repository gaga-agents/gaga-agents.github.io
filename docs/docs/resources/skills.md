# Skills 与工具

Skills 是智能体可发现和调用的外部能力。平台支持云平台 Skills、外部通用 Skills、API、Web 搜索、代码工具与机理模型函数，并通过统一流程管理发现、校验、调用和记录。

## 一个合格的 Skill

一个 Skill 至少要让模型和平台同时理解以下信息：

- **名称与用途**：什么时候应该调用，什么时候不应该调用；
- **输入 Schema**：字段类型、必填项、枚举、长度和格式；
- **输出 Schema**：成功数据、空结果和错误结构；
- **权限与副作用**：只读、写入、删除、付费或外部通知；
- **运行约束**：超时、并发、重试、速率限制和资源上限。

## 接入流程

1. 在当前项目进入 **Skills 工具包**。
2. 选择平台已有能力，或上传/导入外部 Skill。
3. 补充清晰的自然语言描述和结构化参数定义。
4. 使用固定参数独立测试，确认正常、空结果、非法参数和超时路径。
5. 将验证通过的 Skill 绑定到智能体。
6. 在智能体调试轨迹中检查模型选择的工具和参数。

## 安全分级

| 级别 | 示例 | 建议控制 |
| --- | --- | --- |
| 只读 | 查询天气、检索资料 | 超时、限流、结果大小 |
| 可逆写入 | 创建草稿、写入测试表 | 项目权限、幂等键、审计记录 |
| 高风险写入 | 发布、支付、删除、外发消息 | 明确确认、最小权限、审批与回滚 |
| 代码/命令执行 | 数据处理、模型运行 | 沙箱、资源配额、网络与文件隔离 |

## 常见失败

- 工具描述过于宽泛，模型在不合适的场景调用；
- Schema 没有约束必填和枚举，导致无效参数进入后端；
- 重试不可幂等，造成重复写入；
- 把凭据写进 Prompt 或工具描述；
- 只验证成功路径，没有验证超时和外部系统不可用。
