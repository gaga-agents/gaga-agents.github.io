# 路由、并行与交接

编排服务当前的节点类型包括 `condition`、`switch`、`parallel`、`join`、`iteration`、`loop`、`subflow`、`approval`、`transform` 和 `agent_task`。它们对应不同的控制流语义，不应全部用 Prompt 模拟。

## 选择模式

| 模式 | 使用条件 | 关键设计 |
| --- | --- | --- |
| 条件路由 | 根据输入或上一步结果选择一条路径 | 明确条件字段和默认分支 |
| 并行 + Join | 子任务互不依赖或可同时执行 | 定义聚合规则和部分失败策略 |
| 迭代/循环 | 需要重复处理集合或直到满足条件 | 设置最大次数和终止条件 |
| 子流程 | 同一流程在多个场景复用 | 固定输入输出契约 |
| 人工审批 | 高风险操作需人工确认 | 设置 waiting 状态和恢复路径 |

## A2A 交接包

一次交接至少包含 `correlation_id`、调用方、目标智能体、任务目标、输入 Schema、超时、取消、重试和错误分类。只传递目标智能体需要的上下文，避免把整个会话历史无选择地复制过去。

## 并行的陷阱

并行不等于更快：下游限流、共享数据库锁和 Join 等待都可能成为瓶颈。为每个分支记录状态，明确“一个分支失败是否取消全部分支”，并对有副作用的分支使用幂等键。
