# 创建首个项目

项目是平台中资源、权限和运行记录的共同边界。创建智能体之前先创建项目，可以避免模型、工具和知识库失去明确归属。

## 前提条件

- 平台已部署并可访问；
- 你有可用账号；
- 当前账号具有创建项目的权限。

## 操作步骤

1. 登录后进入 **项目管理**。
2. 选择 **新建项目**。
3. 填写能表达业务边界的项目名称和说明，例如“设备故障诊断”而不是“测试项目 1”。
4. 保存后，在顶部项目选择器中切换到该项目。
5. 进入 LLM、Skills、知识库或智能体页面，确认页面显示当前项目上下文。

## 命名建议

一个项目通常对应一个稳定的业务域、团队或交付单元。临时实验可以单独建项目，避免测试模型和工具进入生产项目。资源需要跨项目复用时，应使用明确的共享/授权机制，而不是复制带有密钥的配置。

## 验证结果

创建一个测试资源并刷新页面，确认它只在当前项目出现。切换项目后不应看到未授权资源。如果行为不符合预期，先检查项目选择器和用户权限，再继续创建智能体。
